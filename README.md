# Student Performance Analyzer

An interactive data analytics dashboard built using Python.

## Features
- Upload student marks using CSV
- Calculate class averages and pass rates
- Display grades and student results
- Visualize subject-wise performance
- Identify top-performing students
- Download analyzed results

## Tech Stack
- Python
- Pandas
- Matplotlib
- Streamlit

## Setup

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using pip install -r requirements.txt.
4. Run python -m streamlit run app.py.

## CSV Format

Required columns: Student, Maths, Science, English

Marks must be numeric values between 0 and 100.
